# Aurelia Estates

A premium luxury real estate website designed to showcase high-end residential properties with elegant visuals, smooth animations, and a modern user experience.

## 🌐 Live Demo

https://novaflow-ai-tan.vercel.app/

## ✨ Features

- Luxury Modern UI
- Fully Responsive Design
- Sticky Navigation
- Property Showcase
- Interactive Property Cards
- Search Section
- Featured Listings
- Testimonials
- Contact Form
- FAQ Section
- Google Maps Integration
- Smooth Scroll Animations
- SEO-Friendly Structure

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript

## 📱 Responsive

- Desktop
- Tablet
- Mobile

## 🎯 Purpose

This project was created as a portfolio concept to demonstrate modern frontend development, responsive layouts, and premium UI/UX design for the real estate industry.
